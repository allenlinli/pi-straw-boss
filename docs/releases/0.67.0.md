# pi-straw-boss 0.67.0

Not yet released.

## Fixes from the operate trial (todo #121; [spec](../specs/2026-11-07-link-operate.md), section 11.10)

- **A close from the operate page cleans up the box's route.** Quitting a unit or a squad from the page of a box another computer operates left the route of a main an ally run had opened for that computer, so the computer listed a stoppable "opened main" in unknown state until a stop found it gone or seven days passed. The box's closer now drops that route when the main has quit and its pane or tab closed. A refused or unfinished close drops nothing, and another main's route stays.
- **Refusal notes are in the page's language.** The composer, a wait card and a block answer showed the box's English text on a zh-TW page when the box refused a shell line, a `/boss` command, a draft, a chord and the like. Every reason the box, the keys and the routes give now has a sentence in English and Traditional Chinese; a reason the page has no sentence for still shows the box's text.
- **Both team cards say the grant was withdrawn.** A box in two teams whose operate grant is removed showed 「操作權限已撤銷」 on only one team's card for the minute after. Each team's card now shows it.
- **Earlier runs lists finished runs only.** A main that restarted resumes the same session file, and its run from before the restart was listed beside the live main. A run the box sees live is no longer listed as an earlier run; it appears when the session ends.
- **Not changed:** the box card's folds still close on a page reload (the page keeps no fold by device; remembering these two would be a new mechanism).
