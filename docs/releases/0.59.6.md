`gui:dev` failed to start the page because the page took `ENDING` through `probe.ts`, which pulls in `node:crypto`; the page now takes it from `src/ending.ts` (#105, on `main` as f6a9fbc).

## Zen: a question that blocks an agent comes before a notice

In the 2026-11-06 box trial (trial14, 0.59.5) Zen showed the tower's wait (*MP-4219: Handle, Dismiss, Maybe later*) when a question forwarded by a box arrived, kept it, and left the question behind it with nothing on the page to say so; the box's agent stayed stopped. Boss decision 2026-11-06, 「Blocking first; untouched cards yield」 (Z-D18):

- **Two ranks.** Blocking items go first: a unit that waits or has a dialog, a project trust question, a question a box forwarded, and a teammate's confirm (its tool call waits up to ten minutes). A tower's wait, a pair request, and a memory proposal block no one and come after. Within a rank the order is today's, oldest first. The table with the reason for each kind is `docs/specs/2026-11-01-zen-view.md`, **Blocking first**.
- **A blocking question takes the screen from an untouched lower card**, with the bowl, and the card that was there goes back in line: it is not put aside, so it returns after the answer and the 3 s pause. No count and no hint that it is waiting.
- **A card the boss is answering is never interrupted.** It is touched when its answer is on its way, its context fold or reply box is open, a field has text, a choice is picked, or a tap or key reached it in the last 20 s. The question then waits behind it and takes the screen within half a second of the boss letting go (sending, folding the box, emptying the field, or 20 s with no tap or key). The console says *the card on the screen is being answered*.
- **Unchanged:** Standard's and Geek's dialog order; a question that arrives during the pause or an outcome waits for it; reduced motion; a hidden page reminds once for the question that took the screen.
- **Demo.** `?zen=blocking` shows a tower's wait with a box's question arriving six seconds later (`&box=<ms>` sets the delay).

Design: `docs/specs/2026-11-01-zen-view.md`, **Blocking first**. Code: `gui/zenmodel.ts` (`blocks`, the preempt in `settle`), `gui/zentouch.ts` (the touched card), `gui/zen.ts` (the hook).
