# pi-straw-boss 0.58.1

Released 2026-11-05.

## Upgrading

- Reload every pi session after the update (`/reload`).

## Fixes

- **A restored subagent cut off mid-turn goes on.** After a Herdr restart or a reboot, a subagent whose turn was cut (a tool call with no result, a result nobody read, a message nobody answered) came back idle at its prompt, and on an unattended box nobody noticed. Straw Boss now tells it, once: its last turn was cut by a restart or reboot, the tool call got no result, check the current state before re-running anything that changes state, then continue. A resumed run gets the text as its follow-up; a worktree run, which keeps its pane, gets it over intercom while its intercom status is idle. A run that ended cleanly, one the boss went on with, and one already told are left alone. The launcher's message says which runs were restored mid-turn and whether they were told.
- **The told worktree child knows where to report.** The text sent over intercom now names the launcher and its intercom session id and asks for the final report there, so the launcher that is told to wait for it gets it; the launcher's message no longer also tells it to continue that pane for a run that was told.
- **A run the boss stopped (Esc) is not restarted.** An aborted assistant message with a tool call is the boss's own stop and is no cut.
- **A reply cut by the restart's hangup is a cut.** claude-bridge's `Claude Code process terminated by signal SIGHUP`/`SIGTERM` (or `exited with code 129`/`143`) is told as "your reply was cut off while it was being written". Other errors are not.
- **Smaller:** a restored child is matched only by a current Herdr location; a message that started a turn and got no answer (intercom, monitor wake) is a cut; tool names are quoted only when plain; a turn that stands at a question is left waiting; only the end of the session file is read.

## Known limits

- A draft in the restored pane's editor is kept, but the told child may start its turn before the boss sends it: Straw Boss cannot see another pi's editor, and the guard on the child's side is not part of this release (see [how it works](../how-it-works.md#subagents-a-herdr-restore-brought-back-plain)).
