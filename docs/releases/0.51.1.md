# pi-straw-boss 0.51.1

Released 2026-11-01.

## Upgrading

- Reload every pi session after the update (`/reload`). A session that still runs 0.51.0 shows no Cancel on its question cards.

## GUI

- The question card has a Cancel button beside Send, in the Standard, Geek, and phone layouts. It cancels the open question as Escape does in the terminal: `ask_user_question` ends cancelled, a select gives no choice, a confirm gives No, and a Straw Link gate or approval takes it as Deny. A cancel is never an approval.
- Cancel shows only for a dialog whose owner takes a cancel. robot_hand, secret_drop, and pi-code's confirmations have none.
- A paired device may cancel a dialog where it may pick some choice. Where every choice is this computer's only (the `/boss link decide` approval, `gui rotate`, `gui unpair all`, `server stop` and `restart`), it has no Cancel and a cancel it sends is refused.
