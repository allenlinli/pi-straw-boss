# pi-straw-boss 0.61.1

Not yet released.

## The head's broadcast cards read as what they are (todo #124, [spec](../specs/2026-11-07-head-log-cards.md))

- **A card's parts are labelled.** What the boss said (his own words from the event the relay names), what the head sent, to whom, and when with how many replied are separate lines; the whole texts are one tap away. A card from before this release has no "You said" part and shows the head's first line.
- **A tower that acted is no longer "waiting" for ever.** The server records when a tower's run took the head's message (`已收到`) and when it sent anything in the turn that message started (`已處理`, with the note that it answered someone else, not the head). `已處理` counts as a reply; `等回覆` now means the tower has not taken the message.
- **A correction replaces the order it names.** The head's `tower_send` takes an optional `supersedes` (an earlier ask id); the page folds the replaced broadcasts under the newest one, struck, with `取代 H24` / `已被 H27 取代`. The head is told to set it by its tool description, brief, and prompt.

`asks.json` asks gain `sent`, `boss`, `supersedes`, `read`, and `acted`; older files read unchanged.
