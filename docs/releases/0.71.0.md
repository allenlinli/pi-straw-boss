# pi-straw-boss 0.71.0

Not yet released.

## Windows

- **A cold Windows start no longer waits 41 to 48 s on a PowerShell cmdlet (todo #132).** The first cmdlet of a module that a fresh Windows PowerShell 5.1 meets (`Get-CimInstance`, `Get-Acl`, `New-Object`, `ConvertTo-Json`, `Test-Path`, …) built its module cache, and on a cold windows-11-arm runner that was most of the 60 s the server has to answer `hello` (`breakaway via=failed … "PowerShell did not answer within 60 s"`). The launch and ACL scripts, a process's start time, and the process table now use .NET calls, `[wmisearcher]` (0.2 s), and a small JSON writer; the answers have the same shape and the same start-time text. A test fails when a script calls a module cmdlet. Start times are computed from the CIM datetime string (no DST fall-back error). Constrained Language Mode is not supported (the ACL script already refuses it; start-time and process-table reads need FullLanguage).
