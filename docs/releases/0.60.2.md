# pi-straw-boss 0.60.2

Not yet released.

## The ally base's card says what its units are doing

Boss, on seeing the report of a Straw Link box: "I want that report to be better to look at." The card of an unattended device's base (Standard and Geek; Zen has no such card) was the unit's name, "working · 2 monitors running", and the report as raw text, with the box's own tabs listed above it.

- **A state word and a time.** Each unit says standing by, running, or crashed (待命, 執行中, 當掉) in a colour of its own, and "updated 40s ago" (the page's clock keeps it current). A device whose card names no workspace says each unit's name; otherwise the title is the unit.
- **The report is Markdown, folded.** The last report shows its first line; a tap opens it as Markdown (headings, lists, code, bold), about 24 lines tall at most, scrolling inside. The Markdown is built when it first opens, so a computer with no such device loads none of it.
- **Monitors on one line.** "2 monitors" and their commands, cut with an ellipsis; the whole list is the line's tooltip.
- **A crash says so.** A unit reads *crashed* while a crash notice for it is under 30 minutes old and it is not running again; the notice's text sits behind a fold ("What happened", with its age) instead of in a notice you must clear. An older crash stays in the Link notices.
- **Stale and gone.** Three minutes without a status dims the card in Standard and adds a "no status lately" pill with how long ago the last one came; after thirty minutes the units are gone.
- **Not the box's own mains.** The card no longer lists the tabs the box shares in its presence once it reports units; they come back while it reports none.
- **Phone.** Each fold is a 44 px row. A press on a fold in a row that waits on a question opens the fold and not the question panel.
- **Demo.** `?ally=idle|crashed|stale|long|gone|units` on the demo's ci-box base.

Wire: none. The holder's summary now carries when it took a unit status (`DeviceUnits.at`) and each notice's time (`data.at`); no message changed.

## Fixes

- **A question's notice names the unit the way the card does.** The notice for a question a Straw Link box forwarded read `main _ trial13` while the card, the Link row and the box's own log read `main · trial13`: the controller's label filter turned the middle dot of a tab's session name into `_`. The notice now keeps that one dot (`restrictOwner` in `src/link/text.ts`, used for the unit that asked only), so every place says `main · trial13`. The rest of the name is filtered as before (`Mei's Mac` reads `Mei_s Mac` in the notice), and the labels in a message header keep `restrictLabel`.
