# pi-straw-boss 0.59.2

Not yet released.

## The merge train can be turned off

A computer where a merge and a deploy are the boss's word each time (a desk, say) took the integrator rules anyway: a main sent a car slip, the tower opened an integrator, and `prompts/integrator.md` deployed `auto` targets with no ask. This release adds a switch that takes the whole machinery out. The default is unchanged (on).

- **The switch.** `STRAW_BOSS_INTEGRATION=off` in the environment, or `"integration": "off"` in `<agent folder>/straw-boss/config.json` (the agent folder is `PI_CODING_AGENT_DIR`, else `~/.pi/agent`). The environment wins when it is set and not empty; `off`, `false`, `0`, and `no` turn it off, and any other value, a missing file, or an unreadable one leaves it on. The pi extension of every session reads it, and the tower runs the sb server starts inherit the server's environment, so set it in the environment that starts `herdr server`, or in `config.json`, which every session reads.
- **What off does.** No main or tower takes the integrator role. The main prompt loses the car-slip route and says to ask the boss before merging to a shared branch or deploying; the tower and tower-run prompts lose the forward-to-integrator rule and answer a `shared` request that carries a `car:` block with "integration is off on this computer", opening nothing; `integrator.md` is never loaded, because the folder the prompts point to (`{{dir}}`) becomes a copy, `prompts-off/` in the state folder, that holds `apps-config.md` and `planning.md` without their integration text and no `integrator.md`. `integration`, `stages`, `targets`, and `deploy` in any `apps.json` are ignored; `apps.json` still gives the owning app and its paths.
- **One set of prompt files.** The integration text is marked in place, `<!-- integration -->…<!-- /integration -->` (dropped when off) and `<!-- no-integration -->…<!-- /no-integration -->` (kept only when off), and `src/trainswitch.ts` applies it when a session loads its prompts. With the switch on, a session gets today's text minus the markers; a stray marker fails the session start. Tests: `tests/trainswitch.test.ts`, `tests/prompts.test.ts`, and a tower run in `tests/run-session.test.ts`.

## The train's ledger follows the agent folder

The integrator's ledger folder was written as `~/.pi/agent/straw-boss/trains/` in its prompt, whatever `PI_CODING_AGENT_DIR` said. The main prompt now names the resolved state folder (`{{state}}/trains`, `<agent folder>/straw-boss/trains`), and `integrator.md` points to the folder the role prompt names. This holds with the switch on or off.
