# The head band (2026-11-07)

Status: approved (boss, 2026-11-07)

The map's head node becomes a band across the top of the map. Until now it was a 36 px pill straddling the map's top border (`2026-11-04-head-tower.md`, "Entries"), with curved dashed wires crossing the gaps between cards and its state only in its title. The boss found its place odd: "地圖上的節點位置怪". This spec supersedes that entry's map head node only; the header's crown button, the phone `⋯` and drawer row, and the head page are unchanged.

## The band

| Part | Rule |
|---|---|
| Place | The first thing inside the map, in the flow, the full width of the bases' grid, above it. At most 44 px tall at ≥ 640 px; the bases start under it with the grid's own gap. It scrolls with the map (it is not sticky). |
| Content, left to right | The crown (`iconRef("crown")`), the head's name (`noun("head_tower")`), its state word (the tower unit's mark, as the pill's title had it), the newest line (below), a flexible gap, the waits chip (below), and an "Open" affordance. |
| Newest line | The newest ask row's one-line summary (`2026-11-06-head-page-minimal.md`, "Asks") while one is not lapsed; else the head's newest assistant text, first line, ellipsised to one line; else nothing. Text only: no markdown, no tool cards, and the same filter as the head page's log. |
| Waits chip | `N` waits for the boss, counted exactly as the head page's rows (lapsed waits left out, `bossWaits`); hidden at 0. The crown's news dot (`said` newer than `sb.head.seen`) stays as on the pill. |
| Click | The whole band is one link to `/head` (`data-route="head"`), keyboard focusable, with the state in its accessible name. |
| Absent head | The band shows faint and dashed with the name and "not open", no line and no chip, and still links to `/head`, as the pill did. |
| Phone (< 640 px) | The same band, one line: crown, name, waits chip; the newest line is dropped when it does not fit. Its tap target is at least 44 px tall. |
| Themes | Standard draws it; Geek and Raven Keep restyle it in their own theme CSS (Raven: the keep). Zen has no map and is unchanged. |

## Wires

- The band is the hub (`wire`, `gui/render.ts`). A wire leaves the band's bottom edge and reaches each base's tower with **straight, orthogonal segments only**: down the gutter on the left of the base's column (the map's left padding for the first column), then across into the tower's centre. No curve, no diagonal, and no segment crosses a card.
- The wires of one column share their vertical segment, so a column reads as one trunk with branches.
- The packets keep their rule (one travels a wire while either end works) along the new path; still under `prefers-reduced-motion` and `data-calm`, as now.
- `headWires` stays pure and gains the routing: given the band's bottom, each column's gutter x and each tower's centre, it returns the segments. Its table test covers the first column, a lower card in a column, and no hub.

## Out of scope

The head page's content, the header button, the drawer row, Zen's strip, and the map's base layout (masonry stays).
