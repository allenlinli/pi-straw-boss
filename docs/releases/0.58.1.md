# pi-straw-boss 0.58.1

Released 2026-11-05.

## Upgrading

- Reload every pi session after the update (`/reload`). The first pi session that loads 0.58.1 restarts an older sb server.
- Both computers of a team need 0.58.1 for the whole relay: the computer that sends the work keeps the requester, the computer that does the work opens the main for the device. Either side alone still works as 0.58.0 did.

## Fixes

- **A teammate's report reaches the session that asked for it, and a main opened for a teammate answers that teammate.** Two gaps found in the unattended-box trials, where a Mac tower sent a brief to the box for a local session (無人塔台規劃) and the box opened a main for it.
  - *Mac side.* A tower's `tower_send` with `device` and `reply: true` and no `for` recorded no ask, and a device's answer never enters a tower run, so the report landed in a restricted ally run that cannot write to a local session, and the tower's "I will relay it" had nothing behind it. The server now takes the requester itself: the one live main of the workspace that sent the run a `call_tower` expecting an answer. With none, or two, it binds nothing and the tool result says no session will get the answer, so the tower stops promising a relay. `tower-run.md` tells the tower to pass `for`.
  - *Box side.* `boss_open_main` in an ally run refused the sender `link:<device id>` because no live local session has that id, so the main reported to the box tower and the report waited for that tower's next run. The run now passes `link:<device id>` (or `link:<short id>`) and the server accepts it only for the device the run serves. The main is told to report to the tower alone, and the route the server always made for an opened main wakes a run of that device at once with each report; the ask the run was answering stays with the route, so the final report answers it and reaches the requesting main on the other computer. A device that left the team, another device's run, and a level that needs the boss's confirm are all refused or dropped as before.
