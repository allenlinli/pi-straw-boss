# pi-straw-boss 0.74.0

Not yet released.

## Kinds and tower runs on the ally view

Todo #150, from the boss's question on 11/10 about a box that runs a coordinator, an integrator and trains: the page's ally view drew none of them by kind, and the tower's runs read as agents that opened and closed by themselves.

- **A box's mains show their kind on the ally card.** Each row of a unit's *Mains* fold now says *coordinator*, *integrator*, *standing*, or *train* between the name and the state, in the words the local page uses (the same in every theme; the icons follow below). A main whose pane names no kind draws no word.
- **On the wire.** An entry of the `mains` in a box's `unit-status` gains an optional seventh field, `kind`, at most 16 bytes. The box writes it only to a controller whose fresh `caps` list the new `unit-status.kind` feature beside `unit-status.mains`; every other controller gets the six-field entries of before, so an older device reads what it read. The list is still the mains the controller may stop, not a wider one. The spec's "the ally board carries no role and no kind" is amended ([agent kinds §12](../specs/2026-11-09-agent-kinds.md#12-link-and-remote-devices)).
- **A tower's run is not a unit.** A tower wakes a short run for each message and stands by after it. A tower unit in its `running` or `waking` state now reads *run in progress*, with a tooltip that says it stands by between runs; *running* stays for a plain unit's `working`. On a box's operate base the finished runs (an ally run, an event run, the tower's own) are a closed fold, *Tower runs*, beside the agents' *Earlier runs*, and never rows among the agents.

## Icons by kind

Todo #152, from the boss's 11/11 order that the different kinds of agent be told apart by their icons, on the page and in Herdr's plugin. It reverses [agent kinds D9](../specs/2026-11-09-agent-kinds.md)'s "icons stay by position", recorded as D16.

- **The page.** Every place that drew a unit's role icon now draws its kind's: a coordinator a ship's wheel, an integrator two arrows joining, a standing main a lighthouse, a train the locomotive it already had, and a launched worker, scout, planner, reviewer or watchdog a wrench, binoculars, a pencil and ruler, a magnifier or a hound. That is the map's cards and tokens, the zoomed base, the drawer, the dossier, an alert's face, the chat avatar, and the row of a box's main on the ally card (from the kind the box sends). The tower and the head tower keep their icons, and a unit with no known kind keeps its position's icon (main, member, subagent). The symbols come from the same game-icons.net set and credit as the others (`gui/ICONS.md`); Raven Keep and Geek draw them too (Raven has no twin for a kind, as for the train).
- **Where a launched subagent's kind comes from.** `Unit.duty` now also carries the kind of a subagent a pi-herdr-agents launch started, read from the agent role its launch script names (`PI_SUBAGENT_AGENT`; `visual-tester` and `adversarial-reviewer` count as `reviewer`). A role sb does not know, or a launch script that is gone, leaves it a plain subagent. The operate sanitizer lets the worker kinds through.
- **Herdr's sidebar and the tower's dashboard.** `sb_mark` is now one Nerd Font glyph per kind, checked against Nerd Fonts 3.5.1's glyph names: coordinator nf-md-ship_wheel U+F0833, integrator nf-fa-code_fork U+F126 (as before), standing nf-md-lighthouse U+F09FF, train nf-fa-train U+F238 (as before), worker nf-md-wrench U+F05B7, scout nf-md-binoculars U+F00A5, planner nf-md-pencil_ruler U+F1353, reviewer nf-md-magnify U+F0349, watchdog nf-md-dog U+F0A43. **A coordinator's star is gone**: a main whose kind is unknown (an older sb) keeps it, a member keeps the person, and `[ally]` stays. A launched subagent's mark is its kind's glyph alone; one with no kind keeps `[sub] <launcher>`. The dashboard shows the same glyph before each row's name.
- **Your sidebar rows.** If your `[ui.sidebar.agents]` rows bold the marks, add rules for the two new main glyphs (`\U000F0833`, `\U000F09FF`) to the snippet in [Sidebar net view](../how-it-works.md#sidebar-net-view); a subagent's kind glyph now shows where `[sub]` was hidden.
- **The demo** (`npm run gui:demo`, `gui:dev`) gives its units kinds, and `?kinds` adds a base with a unit of every kind.
