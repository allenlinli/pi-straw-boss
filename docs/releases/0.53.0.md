# pi-straw-boss 0.53.0

Released 2026-11-02.

## Upgrading

- The Windows ACL and PowerShell changes are in the sb server: they take effect once the sb server runs 0.53.0. The first pi session that loads 0.53.0 restarts an older sb server.
- Reload every pi session after the update (`/reload`).

## Windows

- A state folder created from an elevated shell carries an explicit Administrators grant from its creator, and other explicit allow grants (Authenticated Users and the like) can sit on it too. The sb server now removes every explicit allow grant that is not the owner's or SYSTEM's, by SID, on a new folder and on an existing one, so an elevated run passes the ACL check instead of refusing to start. A deny grant is still refused, and the check itself is unchanged.
- The folder's identity is read again after it is protected; an existing folder replaced in between is refused ("replaced while it was protected").
- An sb server started from a PowerShell 7 shell refused to start: PowerShell 7's `PSModulePath` reached Windows PowerShell 5.1, whose `Get-Acl` then failed to load. Every `powershell.exe` the sb server starts (the ACL script, the owner read, the process lineage, the start and firewall commands, and the detached launch) now runs without it.
- A Windows CI job runs the ACL fix on real icacls and Windows PowerShell 5.1.

## Zen view (禪)

- The terminal an answer opens shows inside Zen: a full-screen ink layer with Back to Zen and Esc Esc, which returns to Zen when the step ends. Shift+Esc releases the keyboard from a terminal in Zen and in Standard.
- Several questions in one dialog show the focused one open and the rest as one faded line each; paging moves between them, and the send row stays in view. On a short window the questions get the room and the first option stays whole above the foot edge. Ctrl+wheel zooms.
- The key pad's confirm is a labelled pair in the page's language, the corner menu opens only on a press, and a card takes its size at once and fades instead of easing.
- Zen shows no yellow: the terminal's yellows are ochre and its rows are muted.

## GUI

- Internal: the page's units, view rules, actions, device preferences, and sound playback each live in one module (`units.ts`, `faces.ts`, `pagecore.ts`, `prefs.ts`, `audio.ts`). Behaviour is unchanged.
