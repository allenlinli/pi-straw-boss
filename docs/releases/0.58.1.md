# pi-straw-boss 0.58.1

Released 2026-11-05.

## Upgrading

- Reload every pi session after the update (`/reload`).

## Fixes

- **A restored subagent cut off mid-turn goes on.** After a Herdr restart or a reboot, a subagent whose turn was cut (a tool call with no result, a result nobody read, a message nobody answered) came back idle at its prompt, and on an unattended box nobody noticed. Straw Boss now tells it, once: its last turn was cut by a restart or reboot, the tool call got no result, check the current state before re-running anything that changes state, then continue. A resumed run gets the text as its follow-up; a worktree run, which keeps its pane, gets it over intercom while its intercom status is idle. A run that ended cleanly, one the boss went on with, and one already told are left alone. The launcher's message says which runs were restored mid-turn and whether they were told.
