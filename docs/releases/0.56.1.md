# pi-straw-boss 0.56.1

Released 2026-11-04.

## Upgrading

- Reload every pi session after the update (`/reload`). The first pi session that loads 0.56.1 restarts an older sb server.

## Worktree location

- The main prompt now places a worktree made by hand under `~/.herdr/worktrees/<repo>/<branch>`, beside the ones the `subagent` tool makes. Worktrees opened elsewhere sat in untrusted folders, and a child spawned there waited on pi's "Trust project folder?" prompt without reporting.
- The integrator assembles each train in `~/.herdr/worktrees/<repo>/train-<code>`.

## Zen view

- The idle circle's deck grows from 14 to 38 lines, adding sourced Japanese poetry and prose (Basho, Buson, Issa, Chomei, Kenko, Dogen, Soseki, Santoka, and others). A line can carry its Japanese original, shown in small faint type under the source.
- Lines and their originals wrap balanced on phones.
