## Straw Link team acts in pi

Todo #149 (audit rows 53, 61 to 64): the page's team acts can be typed in pi, as `/boss link leave` and `create` already were.

- **`/boss link invite <team> [unattended <device id>]`** makes an invite (the page's Invite and Invite an unattended device). The text is drawn on a private screen like `invite show`, never as a notice or in the chat. `invite show|cancel <hash>` is unchanged.
- **`/boss link trust <device> reply|forward|dispatch`**, **`role <team> <device> admin|member`**, **`remove <team> <device>`**, **`rotate <team>`** post the routes and bodies the page posts; the holder keeps every check and its refusal is shown as it said it.
- **A `hereOnly` confirm for each write** names the team, the device (label and short id) and the effect; `remove` and `rotate` say what the devices lose (the removed device can no longer read or send and its id is banned; the old team key is retired for the devices that stay).
- **Typed input only.** A tower run or an ally run refuses them, no tool reaches them, and a paired device's composer cannot type them (the verbs are in `BOSS_LINK_LOCAL`, also inside `/boss send` and `/boss open`).
