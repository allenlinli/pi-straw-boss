Run a few agents on the same project and they start stepping on each other: two dev servers on one port, two branches editing the same migration, and no agent knows the others exist.
pi-straw-boss is a [pi](https://github.com/earendil-works/pi) extension that lets them find each other and coordinate, without a scheduler or a new service.

<CardGrid>
	<Card title="Everyone joins" icon="puzzle">
		Each pi in [Herdr](https://herdr.dev) joins its tab's net at start. An agent whose work grows becomes the tab's main agent; a tower opens per workspace when agents start to collide.
	</Card>
	<Card title="Towers coordinate" icon="random">
		A tower routes work between the mains of its workspace and talks to the other towers. Your own head tower takes your instructions and hands each to the workspace that owns it.
	</Card>
	<Card title="See the whole net" icon="laptop">
		`/boss gui` shows every workspace, agent, and subagent live in the browser, and lets you answer what they wait on, from a desktop or a paired phone.
	</Card>
	<Card title="Merge trains" icon="rocket">
		A project can batch its reviewed branches into trains: one review and one run of the heavy gates per train, then deploy and one acceptance page.
	</Card>
	<Card title="Across computers" icon="external">
		Straw Link connects the towers of teammates' computers, and an unattended build box can take work from them.
	</Card>
	<Card title="While you are away" icon="moon">
		Auto mode: tell the head tower you are going to sleep, and no agent waits on you until you are back; what needed you comes back as one list.
	</Card>
</CardGrid>
