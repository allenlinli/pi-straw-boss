# pi-straw-boss 0.67.0

This release fixes what the live operate trial on the unattended box found: a close from the operate page now drops the main's route, refusal notes follow the page's language, a revoked box shows the ended line on every team's card, and Earlier runs lists finished runs only.

## Fixes from the operate trial (todo #121; [spec](../specs/2026-11-07-link-operate.md), section 11.10)

- **A close from the operate page cleans up the box's route.** Quitting a unit or a squad from the page of a box another computer operates left the route of a main an ally run had opened for that computer, so the computer listed a stoppable "opened main" in unknown state until a stop found it gone or seven days passed. The box's closer now drops that route when the main has quit (for a unit, once the broker no longer lists it, up to 30 s after the close was accepted; the page's answer does not wait for that, so a slow quit no longer shows the controller a timeout) and its pane or tab closed. A refused or unfinished close drops nothing, and another main's route stays. The route of a main the box is already stopping at a remote request is left to the revoker, which lets it go with the `unit-stop-done` line and the "stopped" notice, as it did before; the page's close asks it to sweep at once. A main with no stop on it loses its route at once, also when its device had lost `dispatch`.
- **Refusal notes are in the page's language.** The composer, a wait card and a block answer showed the box's English text on a zh-TW page when the box refused a shell line, a `/boss` command, a draft, a chord and the like. Every reason the box, the keys and the routes give now has a sentence in English and Traditional Chinese; a reason the page has no sentence for still shows the box's text.
- **Both team cards say the grant was withdrawn.** A box in two teams whose operate grant is removed showed 「操作權限已撤銷」 on only one team's card for the minute after. Each team's card now shows it.
- **Earlier runs lists finished runs only.** A main that restarted resumes the same session file, and its run from before the restart was listed beside the live main. A run the box sees live is no longer listed as an earlier run; it appears when the session ends.
- **Not changed:** the box card's folds still close on a page reload (the page keeps no fold by device; remembering these two would be a new mechanism).
