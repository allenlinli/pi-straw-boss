# pi-straw-boss 0.70.0

Auto mode arrives: tell the head tower you are going to sleep, confirm once, and no agent waits on you until you are back; what needed you comes back as one list. Also `/boss link on` sets Straw Link up from pi, and the head page's Memory summary is a 44 px tap target on a phone.

## Auto mode

Phase 1 of todo #140 (spec `docs/specs/2026-11-09-auto-mode.md`): the boss can say they are away, and nothing waits for them.

- **`/boss auto [on | confirm | off]` and the head tower's `boss_auto`.** The server holds one state file for the computer; `on` always needs the boss's confirm (a terminal dialog, or the button on the head page and Zen's strip); `off` needs none. The head acts only on the boss's own words (「我要睡了」, 「我起床了」), never a press, and each set of words works once.
- **Waits are refused or cancelled.** `ask_user_question`, `question`, `robot_hand`, `secret_drop`, `link_request`, a browser login, and any confirm inside a tool call are refused with a note; the ones open when it turns on are cancelled (an old `robot_hand` ends the turn and the next turn starts with sb's text). The boss's own commands still confirm.
- **Towers park what needs the boss.** A card recorded while it is on is parked, its raiser is told once (`wait_parked`), a reply that settles a blocked call is listed with its `basis`, and a secret card cannot be started.
- **One return list.** `/boss auto off` prints it, the head gets one event, and `boss_status` shows its summary.
- **An Esc before a decline.** A cancel with no words may be a slipped Esc: the first gets a note, only the second within 10 minutes is a decline.
- **Not in this release:** the header chip and switch, silent parked cards, and the return panel in the GUI (phase 2); `cancel` in pi-robot-hand (an older one gets the turn aborted); the boxes' asks on the list (D6; the list says `not collected`) and the board lines of a setup with `towerRuns` off. In a secondary Herdr slot the head's `boss_auto` is refused and the 30 s backstop does not run; its sessions, towers, and `/boss auto` follow the primary.

## Straw Link

- **`/boss link on` sets Straw Link up from pi.** Until the page's Set up button was pressed, every `/boss link …` line answered "Straw Link is not on in this server" and pi had no way to turn it on. `/boss link on` posts the same `link/enable` route as that button, on this computer only; the "not on" answer now names it.

## Phone

- **The head page's Memory summary is a 44 px tap target on a touch screen.** It was 17 px tall. Its box now takes back the gaps above and below it, so its text keeps its place; the rows under it sit 13 px lower. The map's base name link already took taps over its whole header (64 px); that header now keeps 44 px as a rule. The timeline's marks still take no taps on a phone, by design.
