# pi-straw-boss 0.54.0

Released 2026-11-03.

## Upgrading

- Reload every pi session after the update (`/reload`). The first pi session that loads 0.54.0 restarts an older sb server.
- The package is 2.5 MB (5.4 MB unpacked, 256 files).

## Zen view (禪)

- **Context (H).** An item's card has a 前情 link and the H key: they open the unit's whole history, read-only, under the question, which stays answerable. Esc closes the history first. H does nothing while you type, under an IME, with a modifier, or under a dialog, the menu, or the terminal.
- **Companion stepping.** `[` and `]` (Option or AltGr where the layout needs it) step the companion to the previous or next unit, idle units and towers first. Units that wait on you are never stepped to; they come as items.
- **Command palette.** ⌘K on a Mac, Ctrl+K elsewhere, opens a palette: open the companion's session or terminal, step the companion, settings, the views, the music. It opens from the composer too, but never takes the key from a terminal input.
- **Status strip.** The top line says how many units work and how many are idle. It never says how many wait.
- **Effects.** Three synthesized sounds: a bowl when an item takes the screen, a knock when an answer lands, a low bowl when one is refused. They follow the Sound switch and Volume, wait for the first tap on a phone, and lower the music while they play. The corner menu's *Try the sounds* plays them.
- **Music.** Put your own audio files in `~/.pi/agent/straw-boss-music/` (beside the state folder; MP3, M4A, AAC, OGG, Opus, WAV, FLAC). Zen then shows ♪ in the corner, and ⌄ picks the track when there are two or more; a track loops by cross-fading into itself. With no files there is no ♪. No tracks ship with the package. On a phone nothing plays before the first tap (♪ says *tap to play*, and again after the phone locks), the music pauses while the page is hidden, and the ringer switch mutes it.
- **Layout.** On a phone the status strip has its own place beside the corner buttons; two-line choices no longer overlap; the "jump to latest" pill sits above the composer, not over Send; an open history keeps the whole question in view; the pause is a round breathing circle with no focus ring; trust lists are centred.

## Terminal card

- An accepted answer whose step continues in a terminal (Put it in my prompt, Type it into a new Herdr pane, Run it in a new Herdr pane) opens one small terminal card instead of the full terminal, in Standard, Geek, and Zen. The card shows the waiting line and takes Enter, a typed answer (masked for a password prompt), and Esc; **Full terminal** opens the whole terminal for ssh, editors, and other full-screen programs.
- **One tap.** When Put it in my prompt places a plain `! ` shell line, the card's Run sends Enter at once. A line that changed, emptied, or still completes (Tab) is not run by one tap.

## sb server

- Towers republish their order when a Herdr workspace is created, closed, or reordered, one pass at a time.
- `balance` after-close: a Herdr that is gone ends the wait at once; a busy or closing Windows pipe keeps waiting.

## GUI

- Internal: the answering rules, the session facts, and the per-view keymap each live in one module (`answer.ts`, `sessionfacts.ts`, `hotkeys.ts`); Zen-only code (its key rows, effects, music, companion readers) loads with the Zen chunk, so the page's entry grows by 0.7 KB for all of this. Behaviour is unchanged.
