# pi-straw-boss 0.62.0

Not yet released.

## Link operate: input guards, second round (todo #121 task 4)

- An operate session's keys now go only while the box can confirm what they do. The box's pi reports which keys its live keybindings bind outside the editor (a user's `keybindings.json` can put the external editor or any app action on a chord, Tab or an arrow); a key on that list, or a pi that cannot say, is refused. Every write (key, text, paste, composer, dequeue) also needs pi alone in the pane's foreground by Herdr's process list: an editor started below pi, a nested shell, or an unreadable list refuses.
- A confirmed double-Escape is never sent from an operate session, and the second-Escape refusal no longer waits for Herdr's `idle` status.
- A watch or mirror begun while the session's scope narrows ends with the narrower scope.

## Link operate: input guards, third round (todo #121 task 4)

- Operate no longer refuses a real session. The foreground check wanted pi alone in Herdr's process list, and pi's helper children (claude-bridge's `claude`, MCP servers) share its group; now exactly one `pi` must be listed, and pi's own report that it holds the terminal in raw mode (which it gives up before an external editor or Ctrl+Z) is the proof the editor is pi's. Stop works on these sessions.
- A pad key is compared with pi's bindings by bytes, so pi's other spellings (`return`, `ctrl+m`, `esc`, `alt+left`) cannot slip past. Submit, follow-up, clear and interrupt are allowed only on the keys their guards cover (Enter and Alt+Enter, Ctrl+C, Escape). Ids in `keybindings.json` that pi does not define (extension shortcuts) count as foreign.
- The foreground look moves inside the control job, right before each write. Watches asked twice for one id, or finishing after the session ended, no longer escape the scope.
