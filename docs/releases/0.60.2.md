# pi-straw-boss 0.60.2

Not yet released.

## The ally base's card says what its units are doing

Boss, on seeing the report of a Straw Link box: "I want that report to be better to look at." The card of an unattended device's base (Standard and Geek; Zen has no such card) was the unit's name, "working · 2 monitors running", and the report as raw text, with the box's own tabs listed above it.

- **A state word and a time.** Each unit says standing by, running, or crashed (待命, 執行中, 當掉) in a colour of its own, and "updated 40s ago" (the page's clock keeps it current). A device whose card names no workspace says each unit's name; otherwise the title is the unit.
- **The report is Markdown, folded.** The last report shows its first line; a tap opens it as Markdown (headings, lists, code, bold), about 24 lines tall at most, scrolling inside. The Markdown is built when it first opens, so a computer with no such device loads none of it.
- **Monitors on one line.** "2 monitors" and their commands, cut with an ellipsis; the whole list is the line's tooltip.
- **A crash says so.** A unit reads *crashed* while a crash notice for it is under 30 minutes old and it is not running, and the page has not seen it run since: a unit the boss re-ran and that stands by again no longer reads crashed. The notice's text sits behind a fold ("What happened", with its age) instead of in a notice you must clear. An older crash stays in the Link notices.
- **A trust question is not a crash.** A box that waited ten minutes on a project-trust prompt nobody can answer reads *needs trust* (待信任) in amber, with the fold "Why it stopped", the notice and a line saying to add the project to the box's `trust.json`.
- **Held and closing.** A unit the box holds after repeated crashes reads *held after crashes* (當掉後暫停) in the crash colour; a closing one is said in words, not as the box sends it.
- **Stale and gone.** Three minutes without a status dims the card in Standard and adds a "no status lately" pill with how long ago the last one came; after thirty minutes the units are gone.
- **Not the box's own mains.** The card never lists the tabs the box shares in its presence. While the box reports no units (an older box, a team that shares presence only, the minute after a restart) one line says "3 units online" (3 個單位在線). The subtitle names the box and whether it is there; the units carry the state.
- **The folded line keeps your characters.** The report's first line takes off only Markdown marks that are markup (`**bold**`, `_em_`, `~~gone~~`, code ticks); `ledger.rounding_mode`, `~/projects/app/__init__.py`, `2 * 3` and `MP_4219` stay as written.
- **Phone.** Each fold is a 44 px row. A press on a fold in a row that waits on a question opens the fold and not the question panel.
- **Demo.** `?ally=idle|crashed|stale|long|gone|units` on the demo's ci-box base.

Wire: none. The holder's summary now carries when it took a unit status (`DeviceUnits.at`) and each notice's time (`data.at`); no message changed.

## The drawer's Quit button and the current-row chevron

- **Quit no longer sits under the `›`.** In the phone's all-units drawer, the row of the unit you are on draws a chevron at its right edge; on an idle main the card also holds a Quit button (關掉 in zh-TW), and the chevron was drawn on top of its label. The current row now keeps the chevron's strip clear of the button (the card's right padding is 30 px there, only while a Quit button shows), in English and Traditional Chinese, Standard and Geek. The button keeps its 44 px tap target; no other row or page changes.

## Fixes

- **A question's notice names the unit the way the card does.** The notice for a question a Straw Link box forwarded read `main _ trial13` while the card, the Link row and the box's own log read `main · trial13`: the controller's label filter turned the middle dot of a tab's session name into `_`, and then the server's own notice filter (ASCII only) did it again. The notice now keeps that one dot at both steps (`restrictOwner` and `restrictNotice` in `src/link/text.ts`; the notice's text is ASCII and U+00B7, nothing else), so every place says `main · trial13`. The rest of the name is filtered as before (`Mei's Mac` reads `Mei_s Mac` in the notice), and the labels in a message header keep `restrictLabel`.
