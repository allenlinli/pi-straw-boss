# pi-straw-boss 0.69.0

Not yet released.

## Changes
- **pi-better-show 0.5.0.** Every form, review, checklist, and options block has an "Other comments" box. Its text goes to the agent with the answer ("Other comments: …"), and the locked block shows it. An answer may now carry 65 fields (64 questions and the note) instead of 64. The session that shows the document needs pi-better-show 0.5.0 too: 0.4.0 refuses a document answer whose note is not blank, and the page says so (a chat block is not affected).
